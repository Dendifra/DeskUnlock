# DeskUnlock 0.2.2

## Changes

- Add compatibility with KDE Plasma 6.8's lock-screen heartbeat while retaining support for the legacy timer layout.
- Restore the FingerTouch action when DeskUnlock is configured. Its icon describes the configured integration; it is not a phone-connectivity indicator.
- Store vendor QML snapshots under content-hash-qualified names. Validate existing snapshots before writes, select rollback data by checking the managed QML reconstruction, and retain snapshots after rollback.
- Correct the DMS regression test's literal `execDetached` check.

## Verification

The release checklist requires the Rust workspace suite, CI-pinned lint, Plasma and DMS regressions, Arch package validation, Android build/signature verification, privacy scan, and SHA-256 verification of the release assets.

The release page should list only artifacts actually built and verified. `SHA256SUMS` must cover the exact uploaded source tarball, Arch package, and signed APK.

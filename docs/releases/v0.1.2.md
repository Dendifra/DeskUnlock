# DeskUnlock v0.1.2

DeskUnlock v0.1.2 is a maintenance release focused on public-repository privacy and release-supply-chain controls. It also carries forward the functional fixes from v0.1.1.

## Verified changes

- Hardened tracked-tree and reachable-history privacy checks.
- Added deep auditing for public refs, release assets, checksums, workflow pins, and release-tag authenticity.
- Sanitized public device and build-environment identifiers.
- Pinned GitHub Actions to immutable commit SHAs and kept release publication operator-controlled.

## Release artifacts

The release contains exactly these downloadable artifacts:

- `deskunlock-0.1.2-1-x86_64.pkg.tar.zst`
- `deskunlock-v0.1.2-signed.apk`
- `syauth-0.1.2.tar.gz`
- `SHA256SUMS`

Verify every downloaded file with:

```text
sha256sum -c SHA256SUMS
```

The Android APK is signed with the established DeskUnlock release certificate so it can be installed as an update to v0.1.1.

# DeskUnlock 0.2.3

## Changes

- Prevent the upstream DankMaterialShell translation README's home path from being embedded in `dms-syauth`. The build replaces only the anchored README example and fails closed if the expected line is absent or duplicated.

## Verification

The release checklist requires `make test`, CI-pinned `make lint`, `make privacy-check`, Arch package inspection, Android build/signature verification, and checksums covering the exact release assets. Package and APK builds made before the signed release tag are candidates, not final release artifacts.

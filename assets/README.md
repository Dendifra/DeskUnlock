## DeskUnlock assets

`deskunlock-logo.png` is the canonical DeskUnlock project logo. It was
created specifically for the DeskUnlock project using OpenAI image-generation
tools, generated at the project maintainer's request. To the project's
knowledge, it was not knowingly copied from or derived from third-party
artwork or trademarks.

The logo and illustrations are distributed as part of the DeskUnlock project.

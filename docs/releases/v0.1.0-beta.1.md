# DeskUnlock v0.1.0-beta.1

> **BETA:** DeskUnlock is authentication software. Review the security model
> and test the fallback path before relying on it for daily use.

## What it does

DeskUnlock uses a paired Android phone to approve a Linux desktop unlock with
Android biometric/device-credential confirmation. The Linux side communicates
with the phone locally over BLE/GATT and retains the configured PAM fallback.
No DeskUnlock cloud account or developer-operated backend is required.

## Tested beta scope

- Arch Linux / CachyOS;
- Niri with the validated DankMaterialShell integration;
- Android companion using Bluetooth LE and Companion Device APIs.

Other Linux distributions, desktop environments, Android devices, and OEM ROMs
are not universal compatibility claims.

## Installation overview

- Install the Arch/CachyOS package with normal `pacman` package installation.
- Sideload the signed Android APK using Android's normal package installer.
- Verify the published SHA-256 checksums before installing.
- Pair the computer and phone, then enable DeskUnlock with
  `syauth-control on`.

Detailed steps are in [docs/installation.md](../installation.md) and
[docs/android-setup.md](../android-setup.md).

## Android signing transition

The beta APK is signed with the dedicated DeskUnlock release certificate. The
private release key is not stored in the repository. Users moving from an
older pre-beta/debug APK may need to uninstall it before installing the
release APK and may need to pair again. Do not bypass Android signature checks
or disable Play Protect globally.

## Daily behavior

The lock surface appearing does not itself trigger authentication. The first
genuine mouse movement, keyboard input, or Enter creates one request. Approve
that request with the Android biometric/device-credential prompt. An ignored
request can expire; a later genuine interaction can create another request.

## Privacy and security

The Android manifest does not request `INTERNET`. Pairing material and
cryptographic state remain local to the participating devices. Biometric
approval remains inside Android biometric/Keystore APIs. OS, OEM, Bluetooth,
and Linux host behavior remains outside DeskUnlock's control.

No independent professional security audit has been completed. Report
vulnerabilities using [SECURITY.md](../../SECURITY.md).

## Known limitations

- The validated beta scope is Arch/CachyOS with Niri + DMS.
- Android BLE and background behavior varies by device and ROM.
- Requests can expire if ignored.
- Retry timing and wider distro/desktop portability are not yet polished.
- Debug-to-release signing migration may require reinstall and re-pairing.

# Name and legal notes

## Product name

Working public name:

**DeskUnlock**

Tagline:

**Smartphone authentication and proximity unlock for Linux.**

Repository description:

**Smartphone authentication and proximity unlock for Linux — BLE challenge-response, biometric confirmation, PAM fallback, and desktop integration.**

## Name collision note

`DeskUnlock` is a descriptive name and is already used as a repository/project name by unrelated GitHub users and as a generic phrase for phone-number login functionality.

That does not prevent a repository named `DeskUnlock` under a different GitHub account, but it means the name is not globally unique.

A preliminary web/repository search is **not** a formal trademark clearance. If the project later becomes a commercial product or develops significant branding, obtain a jurisdiction-specific trademark review.

## Copyright/license basis

Upstream `syauth` is MIT licensed.

The upstream license states:

`Copyright (c) 2026 syauth contributors`

The MIT conditions require preservation of the copyright and permission notice in copies or substantial portions.

DeskUnlock therefore keeps the original notice and adds a downstream contributor notice without removing upstream attribution.

## Branding rule

Do not imply that DeskUnlock is an official release from upstream `syauth`.

Do not reuse third-party logos, icons, screenshots, or fonts in repository branding unless their license clearly permits that use.
